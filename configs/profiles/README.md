# Build profiles

One YAML file per build profile, in a folder per class (for example
`warrior/warrior_tank_deep_prot.yaml`). A profile states its target ruleset, phase, level,
content mode, class, role and build label; every scored stat and its weight; caps, soft caps
and thresholds; weapon, proc and set-bonus assumptions; its sources; at least five
hand-reviewed item comparisons it should rank correctly; and a validation status (draft,
validated or experimental). The schema arrives in milestone 2.
