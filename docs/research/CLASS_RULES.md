# Research: Classic Era class rules, races and talents

Gathered 2026-10-07 for the `classic_era` ruleset and the build profiles. warcraft.wiki.gg
mostly describes the current game; each value below is the page's Classic version or the
1.12 value read from the page's patch history. Warcraft Tavern's Classic guides ("WT") fill
in class-level data. Wowhead guide bodies render with JavaScript and could not be read;
Wowpedia on Fandom returned HTTP 402.

## 2. Weapons, dual wield, shields, relics

| Class | Weapons | Source |
| --- | --- | --- |
| Warrior | Every type except wands | WT warrior: "every weapon in the game (with the exception of Wands)" |
| Paladin | One- and two-handed axes, maces and swords; polearms | WT paladin |
| Hunter | Daggers, fist, one- and two-handed axes and swords, polearms, staves, bows, crossbows, guns | WT hunter (thrown: see conflicts) |
| Rogue | Daggers, one-handed swords and maces, fist, bows, crossbows, guns, thrown | WT rogue |
| Priest | Daggers, one-handed maces, staves, wands | WT priest |
| Mage, Warlock | Daggers, one-handed swords, staves, wands | WT mage, warlock |
| Druid | Daggers, fist, one- and two-handed maces, staves | WT druid: "Polearms... cannot be learned by Druids" |
| Shaman | Daggers, fist, one-handed axes and maces, staves; two-handed axes and maces with the Enhancement talent | WT shaman; [Two-Handed Axes and Maces](https://warcraft.wiki.gg/wiki/Two-Handed_Axes_and_Maces) |

- Wands are a caster-only skill ([WT weapon skill trainers](https://warcrafttavern.com/wow-classic/guides/weapon-skill-trainers-and-locations)).
- Polearms require level 20 ([Weapon master](https://warcraft.wiki.gg/wiki/Weapon_master)).
- Dual wield: rogues from level 10, warriors and hunters from 20 ([Dual Wield](https://warcraft.wiki.gg/wiki/Dual_Wield) patch history); shamans could not dual wield until The Burning Crusade.
- Shields: warriors, paladins and shamans ([Shield](https://warcraft.wiki.gg/wiki/Shield)).
- Relics (libram, idol, totem for paladin, druid, shaman) were added in patch 1.10.0 ([Relic](https://warcraft.wiki.gg/wiki/Relic)).

## 6. Dual wield

Off-hand weapons deal 50% damage ([Dual wield](https://warcraft.wiki.gg/wiki/Dual_wield));
Dual Wield Specialization adds up to 25% (warrior) or 50% (rogue). The dual-wield miss
penalty applies to white hits only.

## 7. Levels

Level cap 60, Classic built on patch 1.12 ([Level cap](https://warcraft.wiki.gg/wiki/Level_cap),
[World of Warcraft: Classic](https://warcraft.wiki.gg/wiki/World_of_Warcraft:_Classic)).
Skull bosses count as three levels above the player ([Boss](https://warcraft.wiki.gg/wiki/Boss)).

## Conflicts

1. Hunters and thrown weapons: WT leaves them out; [Thrown](https://warcraft.wiki.gg/wiki/Thrown)
   says hunters knew Throw until patch 4.0.1. The ruleset allows them and records the conflict.
2. Orc fist weapons: one list gives orcs +5 fist; the Axe Specialization history says fist
   weapons were added in 3.2.0. The ruleset gives axes only.
3. Shaman two-handed weapons need the Enhancement talent; the ruleset allows them and notes it.
4. Dual-wield miss: a flat +19% (2021 test) versus 0.8 x miss + 20%; see COMBAT_TABLES.md.
